# Design direction

Afterglow is a handheld lighting instrument. Its main element is a colour ring with a preview in its centre. It shows the selected light, not a claim about the strip's current output.

Palette: midnight blue #131d32, panel blue #1c2942, lavender #c5beff, mist #edf0ff, muted slate #a6b4cc and peach #f6c4a5. The colour spectrum is functional, and the rest of the interface stays quiet. Typography uses the rounded system face on iPhone and Segoe UI on Windows, with clear numerals and a compact heading scale. This avoids remote font dependencies.

Phone layout: brand, connection bar, power row, colour dial, saturation and brightness, named presets, then editable favourites. At wider widths the dial sits beside the controls. Alignment is left except the dial preview. Connection stays near the top and the apply action stays within thumb reach at the bottom. Rounded controls distinguish touchable areas from the plain background. No hero illustration or unrelated dashboard metrics.

Review against the brief: a decorative room scene would consume space needed for controls. The ring itself supplies the distinctive visual element. A power toggle would imply knowledge the protocol cannot provide, so the design uses explicit On and Off actions with command status wording. Nothing animates without user interaction, and all colour operations have labelled keyboard controls.
